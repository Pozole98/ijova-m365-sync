Guía de Comandos CLI en Terminal (Operaciones de Lote)

Las tareas masivas de inicio de ciclo escolar y auditoría profunda se ejecutan directamente en la terminal de Linux. Haz clic en cualquier comando para copiarlo.

🚀

Aprovisionamiento Masivo (Crear Alumnos Nuevos)

Lee el archivo Excel, identifica quiénes no tienen cuenta y crea los usuarios en Microsoft Entra ID asignándoles su licencia Office 365 A1.

python3 main.py apply
🛡️ Garantía: Cero escrituras en cuentas de alumnos existentes.
🌐

Simulación DRY-RUN en la Nube

Compara el listado escolar contra todo el tenant de Entra ID sin realizar ningún cambio ni tocar licencias. Genera un reporte previo.

python3 main.py dry-run
🛡️ Garantía: 100% lectura segura (Cero escritura).
🔍

Validación Offline del Archivo Excel

Revisa que las matrículas cumplan la norma de 6 dígitos, detecta duplicados y normaliza nombres sin requerir conexión a internet.

python3 main.py validate
🛡️ No consume cuotas de API ni altera ningún registro.
🎓

Alta Rápida de Alumno Extemporáneo

Crea interactivamente una sola cuenta de alumno que llegó después del inicio de ciclo y actualiza de inmediato el archivo Excel.

python3 main.py enroll
🛡️ Genera ficha de bienvenida de entrega inmediata.
🔑

Reseteo Masivo de Todo el Colegio (--all)

Genera nuevas contraseñas temporales para todos los alumnos activos en Microsoft 365 con un solo comando para inicio de semestre.

python3 main.py reset --all
🛡️ Requiere confirmación expresa 'RESETEAR' para ejecutarse.
📑

Bajas Masivas desde Archivo Excel

Da de baja a toda una lista de alumnos (por ejemplo, egresados o graduados) leyendo una columna de matrículas desde un archivo Excel.

python3 main.py delete --excel "Bajas.xlsx"
🛡️ Envía a papelera por 30 días liberando las licencias A1.
📸

Auditoría Concurrente y Descarga de Fotos

Descarga masivamente las fotos de perfil de todos los alumnos en segundo plano con múltiples hilos y genera una galería HTML local.

python3 main.py photos -w 8
🛡️ Exporta auditoría a Excel en reports/auditoria_fotos_perfil.xlsx.
💾

Respaldo Snapshot de Auditoría

Descarga un volcado completo con timestamp de todos los usuarios, UPNs y licencias del tenant en formato JSON en backups/.

python3 main.py backup
🛡️ Respaldo protegido con permisos de archivo 0700.
